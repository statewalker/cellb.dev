## Cap'n Web does not fit; a reference table does

Checked before writing code (`capnweb` 0.12.0, 2026-08-20, MIT, no dependencies, 100 KB / 22 KB
gzipped `dist/index.js`), over a Node `MessageChannel` with `newMessagePortRpcSession`:

| Value cellb passes today | Cap'n Web 0.12.0 |
|---|---|
| `Date`, `Uint8Array`, `ArrayBuffer`, `bigint`, nested plain objects | kept |
| `Map`, `Set`, `RegExp` | **refused**: `Cannot serialize value: [object Map]` |
| an error's `code` | kept; a custom `name` becomes `Error` |

`worker-details` `/rpc` returns a `Map` from a Durable Object and checks it arrives as one (celld
and workerd agree). Cap'n Web also only knows its own `RpcTarget` class and its own stubs: cellb's
stubs (Proxies over `{}`) would serialize as empty objects unless every one were wrapped. So the
§7 alternative: a reference table on the existing webrun-rpc calls port, values still
structured-cloned by the port. No pipelining (nothing in the proof needs it).

## Design

**One crossing rule** (`src/core/handles.ts`, `cross`): functions, `RpcTarget` instances, cellb
stubs and class handles pass by reference; arrays and plain objects are walked; anything else is
structured-cloned. Stubs answer a `STUB` symbol. Two values refuse to cross, with workerd's
`DataCloneError` texts, through a `REFUSE` symbol:
`ctx.exports.<Entrypoint>` not called with `{ props }` (`LoopbackServiceStub`), and a loaded
Worker's `getEntrypoint()` stub (`Entrypoints to dynamically-loaded workers cannot be transferred
…`). `cross` replaces `namespace.ts`'s `cross` (which refused `RpcTarget`) and `handles.ts`'s
`clone`.

**Across the isolate** (`src/isolate/protocol.ts`, `callsOver`): each side keeps a table of the
values it exported. Outgoing messages and results are walked with the same rule; a by-reference
value becomes `{ "\u0000ref": id }`. Incoming ones turn each marker into a proxy: calling it, or a
method of it, is a `ref` call back to the owner. `proxy[Symbol.dispose]()` (or garbage collection,
via `FinalizationRegistry`) sends `release`; the owner drops the entry and, when no entry holds the
value any more, calls the value's own `Symbol.dispose` (workerd's rule for an `RpcTarget`). This
replaces `splitEnv` and the `stub` message: `env` and `globalOutbound` cross by the same rule.

**`getEntrypoint(name, { props })`** checks `props` at once; a refusal returns a rejected promise
(so `await` and `assert.rejects` see the `DataCloneError`).

**Plain-object `ctx.exports`**: an exported object with methods is an entrypoint stub
(`ctx.exports.bindingsInProps.run(stub)`).

**Storable stubs** (`allow_irrevocable_stub_storage`): a `ctx.exports.X({ props })` entrypoint stub
or class handle carries `{ name, props }` under an `EXPORT` symbol. `src/v8/serialize.ts` takes a
host-object hook (V8's `\` tag); the runtime's default codec writes those as `[name, props]` and
reads them back as `ctx.exports[name]({ props })`. Other stubs and `RpcTarget`s refuse
(`DataCloneError`) instead of being stored as `{}`. A facet started from a class handle with props
gets them as `ctx.props`.

**Not covered** (stated in `docs/gaps.md`): stubs to objects on another node (cells-link, celld
peer) — refused, not by reference; class handles across the isolate; promise pipelining.
