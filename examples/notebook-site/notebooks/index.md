# Notebooks on cellb

These pages are Markdown notebooks. Their code cells were transpiled by notebook-kit, the site
around them is an Astro theme, and both run on cellb.

## A reactive cell

The next cell defines `answer`; the one after it displays it.

```js
const answer = 6 * 7;
```

```js
answer
```
