CellB examples

Cloudflare Workers apps run on CellB entirely in a browser tab: a static file server sends the files, and the tab runs the Worker, its Durable Objects, D1, KV and R2 (SQLite as WebAssembly, on OPFS). Keep the host tab open while you use a site.

EmDash, served from a tab

EmDash, the Astro CMS, as Astro builds its blog-cloudflare template for Cloudflare, unchanged. Run the setup wizard at /_emdash/admin, create an account with a passkey, write and publish posts; they stay in this browser.

Astro, built in the tab

The app's sources are built in the tab (esbuild and Astro's compiler as WebAssembly, packages from the npm registry), then run there on CellB: a small Astro app in a few seconds, or EmDash in about two minutes the first time. One app at a time per origin: building the other replaces it.

Each example has its own host: its ServiceWorker takes the whole origin. Sources: examples/.
