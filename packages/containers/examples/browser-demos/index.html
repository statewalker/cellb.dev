Python in Wasmer containers

Run a Python script against files from this page. Each run gets a fresh Python container (Wasmer's python/python) in a worker of its own, terminated after the run. The script sees only its files at /data, and has no network.

Wasmer is the isolation boundary: run code you do not trust here.
