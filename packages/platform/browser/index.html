webrun platform in a tab

This tab runs the whole platform on cellb: the package store, the ESM CDN, the project module servers, the bundler (esbuild-wasm) and the notebook builder, each a Durable Object in SQLite on OPFS inside a Dedicated Worker. A ServiceWorker routes this origin to it. Keep the tab open while you use it.
